# post-ai-services

تشخیص محتوای تبلیغاتی و محتوای ممنوع در متن‌های فارسی.

این مخزن مستقل از Topic Classifier است. آن پروژه سرویس جداگانه‌ای برای دسته‌بندی موضوعی است و امروز با `POST /classify` کار می‌کند. اتصال این دو در آینده ممکن است. این مخزن آن سرویس را صدا نمی‌زند.

منطق تشخیص، هماهنگ‌کنندهٔ پایپ‌لاین و API هنوز در این مخزن نیست.
